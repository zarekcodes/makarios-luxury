/ disclosure, so it opens and closes with no JavaScript at all. Three things about it are deliberate: 1. It is a panel anchored under the header, not a full-screen overlay. It covers the top of the page rather than the whole of it, which means it is not a modal: no focus trap, no Escape handler, no aria-modal and no scroll lock — none of which could be built without JavaScript anyway. Tab order is already correct, because the links follow in the DOM. 2. There is NO hand-written aria-expanded on the . Without JavaScript it could never be updated, and a permanently wrong value is worse than none. Browsers already expose a disclosure's open state. 3. The desktop and mobile navs are separate elements sharing one link file. Only one is ever displayed, so only one reaches the accessibility tree, and resizing past the breakpoint can never leave the menu stuck open. A page can set `header_overlay = true` (the home page does) to float the header over a full-bleed hero photograph instead of sitting above it.
