Used directly by a inside a , where the hero offers a different crop per screen shape (art direction), and by responsive_img below. #} {% macro srcset(name, widths, mount="static") -%} {%- set candidates = [] -%} {%- for w in widths -%} {%- set _ = candidates.append(image_url(name, w, mount) ~ ' ' ~ w ~ 'w') -%} {%- endfor -%} {{ candidates | join(', ') }} {%- endmacro %} {# responsive_img(...): a complete . Getting this roughly right is what makes srcset actually save bytes. alt describe the picture; "" only for decoration width intrinsic width of the default file height intrinsic height of the default file eager true for the LCP image (the hero).
